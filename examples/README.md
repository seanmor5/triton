# Examples

A guided tour of Triton-Elixir, from "hello world" to things only the BEAM can do. Each script is self-contained, verifies its own results, and runs with `source scripts/env.sh && mix run examples/<file>.exs` (all require a CUDA GPU). Start with [`01_vector_add.exs`](01_vector_add.exs), which walks one kernel through the whole stack: `defkernel` tracing, the generated TTIR, the pure-Elixir reference interpreter, the native MLIR → PTX → CUBIN pipeline, and a bandwidth benchmark. [`02_softmax.exs`](02_softmax.exs) fuses a full softmax row into one kernel with axis reductions and cross-checks interpreter, GPU, and a plain-Elixir reference. [`03_matmul_autotuned.exs`](03_matmul_autotuned.exs) shows the symbolic `for ... range ... reduce` loop compiling to a real `scf.for`, then lets `Triton.Autotuner` compile ~26 tensor-core matmul configs concurrently on the BEAM and race them on the GPU, printing a timing leaderboard and TFLOPS. [`04_flash_attention.exs`](04_flash_attention.exs) implements single-head flash attention with an online softmax, carrying `{acc, m_i, l_i}` through one multi-carry loop, verified against a plain-Elixir attention. [`05_hot_kernel_server.exs`](05_hot_kernel_server.exs) is the OTP showcase: a GenServer owns a compiled kernel and serves GPU requests while the autotuner finds a faster config in a background Task, which is then hot-swapped in mid-traffic — atomically, with zero dropped requests. [`06_nx_defn.exs`](06_nx_defn.exs) shows the Nx integration: every `defkernel` is callable with Nx tensors — kernels declare their outputs and launch grid at the definition (`out:`/`grid:`), so `softmax(x, cols)` allocates, launches, and returns — EXLA CUDA tensors pass in zero-copy as device pointers, and the same call works directly inside `Nx.Defn` pipelines. Building on that, [`07_layernorm_fused.exs`](07_layernorm_fused.exs) writes a one-pass fused layernorm as an Nx tensor function and checks it against EXLA-jitted Nx, and [`08_flash_attention_nx.exs`](08_flash_attention_nx.exs) races flash attention as a drop-in Nx function against XLA's materialized `softmax(QKᵀ)V` — XLA wins short sequences, flash attention wins from seq≈8k and the gap widens quadratically (2x at seq=16384, where the score matrix XLA materializes is 1 GiB). The full sweep lives in `bench/nx_vs_triton_bench.exs`. Closing the loop, [`09_axon_triton_layer.exs`](09_axon_triton_layer.exs) puts a Triton layer inside an Axon model: a single-head transformer encoder block built twice from the same weights — once with attention spelled in Nx (materialized), once with the flash attention kernel as a `stablehlo.custom_call` — both compiled by EXLA into single XLA programs, raced across sequence lengths (the Triton layer wins from seq≈8k, 2.2x at 16k).
